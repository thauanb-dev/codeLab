# 🕶️ NeroSINT

> **OSINT // INVESTIGATE // CONNECT**

NeroSINT é uma plataforma de **Open Source Intelligence (OSINT)** desenvolvida para centralizar consultas, análise e relacionamento de informações públicas em uma interface inspirada em terminais de investigação.

O projeto está sendo desenvolvido com **Next.js + TypeScript + React**, priorizando uma arquitetura modular, comandos independentes e uma interface simples, rápida e orientada à investigação.

## 🧠 O que é o NeroSINT?

O NeroSINT nasceu da ideia de transformar diferentes consultas OSINT em uma única interface.

Em vez de utilizar diversas ferramentas separadamente, o objetivo é criar um ambiente onde o investigador possa executar consultas através de comandos:

nerosint:~$ cnpj 07038163000102
